# 飞书多维表格结构总览

> 整理日期：2026-06-19 | 共 13 张表，5 个业务模块

---

## 一、排单引擎（5 张表）

### 1.1 销售订单主表

合同级，一个合同一行。OA Excel 导入，排单/财务/客服均读取。

| 字段 | 类型 | 说明 |
|------|------|------|
| 合同编号 | 文本 | 主键 |
| 下单日期 | 日期 | |
| 客户名称 | 文本 | |
| 项目名称 | 文本 | |
| 商务 | 文本 | |
| 代理商 | 文本 | |
| 是否紧急/换货/补发/维修 | 文本 | 默认"否" |
| 订单来源 | 单选 | OA下单 / 微信群预下单 |

### 1.2 销售订单明细表

SKU 级，一个合同多行。含 AI 回填的库存分析字段。

| 字段 | 类型 | 说明 |
|------|------|------|
| 合同编号 | 文本 | 必填 |
| 合同数量 | 数字 | 必填 |
| 产品名称 / 规格 | 文本 | |
| SKU编码 | 查找引用 | ← SKU标准表 |
| 项目名称 | 查找引用 | ← 销售订单主表 |
| 已分配数量 / 库存可用量 / 缺口数量 | 数字 | **AI回填** |
| 库存状态 | 文本 | **AI回填**（有货/缺货） |
| 置信度 | 单选 | **AI回填**（高/中/低） |
| 预计到货日期 | 日期 | **AI回填** |
| 排单批次号 | 文本 | **AI回填** |

### 1.3 AI排单总表

按合同聚合的排单结果。AI 写 `待确认`，人工改 `已确认`/`已发货`。

| 字段 | 类型 | 说明 |
|------|------|------|
| 合同编号 | 文本 | 主键 |
| 项目类型 / 项目名称 / 客户名称 | 文本 | |
| 订单SKU总数 / 订单总数量 | 数字 | AI生成 |
| 缺货SKU数 / 缺货SKU列表 | 数字/文本 | AI生成 |
| 整体状态 | 文本 | 有货/缺货/部分缺货 |
| AI建议发货时间 | 日期 | AI生成，工作日顺延 |
| AI风险 / AI建议 | 文本 | AI生成 |
| 订单状态 | 文本 | AI写"待确认"，**绝不覆盖人工的"已确认"/"已发货"** |
| 是否人工确认 | 单选 | 是/否 |
| 人工确认发货时间 | 日期 | 人工填写 |

### 1.4 库存预留表

待确认订单的库存占用记录，参与库存可用量扣减。

| 字段 | 类型 | 说明 |
|------|------|------|
| 预留ID / 合同编号 / SKU | 文本 | |
| 预留数量 | 数字 | |
| 批次号 / 创建时间 | 文本/日期 | |
| 状态 | 文本 | 有效 → 已转换/已过期 |
| 释放原因 | 文本 | |

### 1.5 库存快照表

ERP 导出的库存数据。

| 字段 | 类型 | 说明 |
|------|------|------|
| SKU | 查找引用 | ← SKU标准表 |
| 库存数量 | 数字 | 必填 |
| 库存日期 / 待采购出库 / 在途数量 | 日期/数字 | |
| 数据来源 | 单选 | ERP导出 / 手动录入 |

## 二、财务核算（3 张表）

### 2.1 财务对账总表

合同级对账汇总。**人工核对金额非空则整合同锁定**，同步和核算均跳过。

| 字段 | 类型 | 说明 |
|------|------|------|
| 合同编号 | 文本 | 主键 |
| 下单日期 | 日期 | 从主表同步 |
| 客户名称 | 文本 | 从主表同步 |
| 项目名称 | 文本 | 从主表同步 |
| 商务 | 文本 | 从主表同步 |
| 代理商 | 文本 | 从主表同步 |
| 项目类型 | 单选 | 🔒 人工选择（包干/单采），**同步不覆盖** |
| 备注 | 文本 | 🔒 人工填写，**同步不覆盖** |
| AI项目金额 | 数字 | 🔒 核算回写（明细表小计汇总），**同步不覆盖** |
| 人工核对金额 | 数字 | 🔒 人工填写，**非空即锁定整个合同** |
| AI费用检查 | 文本 | 🔒 核算回写（正常/异常描述） |

> 🔒 = 同步保护字段（同步数据时不覆盖，保留人工值或核算结果）

### 2.2 财务对账明细表

SKU 级核算明细。按 合同编号+产品名称+规格 做 Upsert。

| 字段 | 类型 | 说明 |
|------|------|------|
| 合同编号 | 文本 | 复合键 |
| 产品名称 | 文本 | 复合键 |
| 规格 | 文本 | 复合键 |
| 合同数量 | 数字 | 从明细表同步 |
| 项目名称 | 文本 | 从主表关联 |
| 合同类型 | 单选 | 🔒 从对账总表同步（包干/单采） |
| Spec_ID | 单选 | 🔒 三层匹配（精确→别名→关键词），动态选项 |
| 是否计入包干 | 单选 | 🔒 核算判断（是/否） |
| 包干合同单采数量 | 数字 | 🔒 核算计算 |
| 单采价格 | 数字 | 🔒 核算计算 |
| 小计 | 数字 | 🔒 核算计算 |

> 🔒 = 同步保护字段（核算结果保留不覆盖）

### 2.3 产品计费规则主表 ⚠️

| 字段 | 类型 | 说明 |
|------|------|------|
| 产品大类 | 文本 | 产品分类 |
| 产品名称 | 文本 | 匹配明细表的产品名称 |
| 规格型号 | 单选 | 动态添加选项 |
| Spec_ID | 单选 | 规格唯一标识，动态添加选项 |
| 计费方式 | 单选 | 单采 / 包干 |
| 包干阈值 | 数字 | 包干内数量上限 |
| 单采单价 | 数字 | 超出阈值或单采项目的单价 |
| 阶梯单价 | 数字 | 暂不启用，预留字段 |
| 特殊说明 | 文本 | 人工备注，不影响核算 |
| 别名 | 文本 | 模糊匹配用（支持包含关系） |

> ❌ **代码永不写入此表，仅人工维护**

## 三、发货与日报（2 张表）

### 3.1 AI发货总表

合同级发货记录。**顺丰 API 自动下单**，物流状态定时轮询更新。

| 字段 | 类型 | 来源 | 说明 |
|------|------|------|------|
| 合同编号 | 文本 | AI写入 | 主键 |
| 客户名称 | 文本 | AI写入 | |
| 项目名称 | 文本 | AI写入 | 用于构造收件地址中的项目标识 |
| 收件人 | 文本 | AI写入 | 下单时必填，可从客户信息表引用 |
| 收件电话 | 文本 | AI写入 | 下单时必填 |
| 是否发货 | 文本 | 🔒 人工填写 | 是/否 |
| 发货日期 | 日期 | 🔒 人工填写 | |
| 快递公司 | 文本 | 🔒 顺丰API回填 | 自动填写"顺丰速运"；保护人工先于系统的写入 |
| 快递单号 | 文本 | 🔒 顺丰API回填 | 下单成功回写；防重复下单检查 |
| 物流状态 | 文本 | 🔒 顺丰API回填 | 待揽收 / 运输中 / 派送中 / 已签收 / 异常 |
| 物流更新时间 | 日期 | 🔒 顺丰API回填 | 最近一次物流轨迹更新时间 |
| 物流详情 | 文本 | 🔒 顺丰API回填 | 最新轨迹描述 |
| 备注 | 文本 | 🔒 人工/API | 人工可编辑；API异常时写入错误信息 |

> 🔒 = AI 写入时保护不覆盖；物流字段由顺丰定时轮询（每2小时，8:00-20:00）更新
> 物流状态已签收后不再参与轮询；颜色条件：待揽收灰/运输中蓝/派送中橙/已签收绿/异常红

### 3.2 AI排单日报表

每次排单生成一行统计（24 个字段），供日报机器人和三线推送。

主要统计维度：订单总数/新增/紧急、排单完成率、库存SKU充足/预警/缺货数、最紧缺物料、发货预测（当日/3天/7天）、排单占库存比例。

## 五、表间数据流

```
OA Excel 导入
     │
     ├──→ 销售订单主表 ──────────→ 财务对账总表
     ├──→ 销售订单明细表 ──────────→ 财务对账明细表
     └──→ 库存快照表
              │
         SKU标准表（Lookup引用源）
        客户信息表（Lookup引用源）
              │
         AI排单引擎（库存匹配 + 产能调度）
              │
     ┌────────┼────────┐
     ▼        ▼        ▼
AI排单总表  库存预留表  AI发货总表
     │                    │
     ▼                    ├── 顺丰API（下单 + 物流轮询）
AI排单日报表               │
                          ▼
                    客户信息表 ←── 收件人/收件电话引用

产品计费规则主表 ──→ 财务对账明细表（Spec_ID匹配，只读）
```

### 安全边界

| 表 | AI 写入限制 |
|----|------------|
| 产品计费规则主表 | ❌ 永不写入 |
| 客户信息表 | ❌ 仅读取，不写入（人工维护） |
| 财务对账总表 | 仅 AI项目金额 / AI费用检查；人工核对金额非空完全锁定 |
| 财务对账明细表 | 仅核算结果 4 字段（是否计入包干/包干合同单采数量/单采价格/小计）；同步不覆盖已有核算数据 |
| AI排单总表 | 仅 `待确认`；`已确认`/`已发货` 绝不覆盖 |
| AI发货总表 | 仅基础信息（合同编号/客户名称/项目名称/收件人/收件电话）；物流字段由顺丰API回写；人工已填写字段保护不覆盖 |
| 库存预留表 | 排单引擎写入预留记录；状态由"有效"→"已转换"/"已过期" |
| AI排单日报表 | 每次排单追加一行；历史行不修改 |
