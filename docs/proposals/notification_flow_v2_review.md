## 三方共认的 TOP 3 改进

### 1. 紧缺物料改为三维展示
```
SKU名称 + 受影响合同数 + 缺口数量 + 预计到货日（可选）
```
三个维度同时出现，排单员才有真正的决策依据。

### 2. 加入超时兜底（修改原"不做"的决策）
排单完成后启动30分钟计时。超时后自动群发 + 日报表标记"超时自动确认" + 群消息标注"系统自动发送"。

### 3. 中间态通知改为摘要预览
不写"等待确认中"，改为：
```
今日排单完成（61合同）
紧缺12种物料，影响23合同
完整报告确认后推送
```
采购群得到可行动的信息，而非纯等待。
