# 三路AI评审汇总 & 修订方案

## 评审阵容

| 评审角色 | 核心视角 | 评分 |
|---------|---------|------|
| UI Designer 专家 | 视觉层次 / 色彩 / 排版 / 可访问性 | **7.0/10** |
| 供应链运营总监 | 业务决策 / 操作闭环 / 管理合规 | **33/60 (55%)** |
| 飞书平台技术工程师 | 协议兼容 / 实现可行性 / 容错 | **方案需修订** |

---

## 核心共识

三路评审一致认可的核心方向：

1. **去掉 emoji 用结构性元素替代** — 三方全部支持
2. **数字仪表盘优于大段文字** — 三方全部支持
3. **三卡差异化信息策略** — 方向正确
4. **信息密度压缩**（尤其 Boss 卡片） — 方向正确

## 关键差异

| 议题 | UI Designer | 运营总监 | 技术工程师 |
|------|-----------|---------|-----------|
| 卡片合并 | 认为是亮点 | 非常支持 | **技术不可行**，不同通道/不同数据 |
| 四格仪表盘 | 建议 2×2 网格 | 接受 | **飞书无 grid，column_set 最多 3 列** |
| 高亮区域 | 推荐 background-color | 推荐 | **飞书不支持自定义背景色** |
| 操作按钮 | 未特别关注 | **P0 缺确认按钮是致命缺陷** | 建议增加降级保护 |

## 致命问题（必须解决才能落地）

### 🔴 问题 1：Card 2 排单员缺"确认排单"操作按钮

**运营总监指出**：两个按钮"查看排单总表"和"审计记录"全是"看"，没有"做"。排单员从"操作者"变成了"旁观者"。

**修订方案**：恢复"确认排单"按钮作为 primary action，另加"查看排单总表"作为 secondary。

### 🔴 问题 2：飞书协议不支持 grid、自定义背景色、左侧色条

**技术评审指出**：设计方案中的视觉效果（grid 布局、高亮区块 background-color、左侧 6px 色条）在飞书卡片 API 中无法直接实现。

**修订方案**：用飞书协议原生支持的方式达成近似效果：
- 仪表盘 → `column_set` trisect（最多 3 列）/ markdown 表格
- 高亮区域 → `<font color='red'>` 内联着色 + `hr` 分隔线
- 左侧色条 → header template 色
- 四格 → 2+2 双列或 markdown 表格

### 🔴 问题 3：`_send_personal_notification` 和 `_build_planner_card` 不能合并

**技术评审指出**：两个函数在不同文件、不同通道、不同数据依赖（一个有 DataFrame 明细，一个只有 report dict）。

**修订方案**：保持独立，但统一视觉语言。

## 色盲可访问性修正

**UI Designer 指出**：8% 男性用户有红绿色觉障碍。

修正方案（双通道编码）：

| 状态 | 颜色（视觉） | 形状/文字（第二通道） |
|------|------------|-------------------|
| 阻断 | 红色 | 加粗 + "阻断"文字标签 |
| 警告 | 琥珀色 | "⚠ 关注"文字标签 |
| 正常 | 绿色 | "✓ 正常"文字标签 |
| 信息 | 蓝色 | 普通 weight |

## 设计规范最终定稿

### 色彩体系

```
阻断/严重： #A32D2D (c-red 800)  → 交付阻断、SLA超期
警告/关注： #D97706 (amber 700)  → 预警库存、产能紧张  [已加深以提升对比度]
正常/通过： #3B6D11 (c-green 800) → 交付正常、库存充足
信息/操作： #185FA5 (c-blue 800)  → 确认通知、数据链接
```

### 排版映射（飞书协议兼容版）

| 层级 | 飞书实现 | 用途 |
|------|---------|------|
| 卡片标题 | header.title (`plain_text`) | 卡片主标题 |
| 核心指标值 | markdown `**数字**` + `<font color>` | 仪表盘数字 |
| 指标标签 | markdown 普通文本 | "交付率""延迟订单" |
| 区块标题 | markdown `**标题：**`（加粗） | "最紧急物料""AI洞察" |
| 辅助信息 | markdown 小号文本 | 其他断供列表 |
| 脚注 | `note` 元素 | 批次号、时间戳 |

### 按钮规范

每张卡片 **至少 1 个、最多 2 个** 按钮：

| 卡片 | Primary 按钮 | Secondary 按钮 |
|------|------------|---------------|
| Card 1 | 确认排单 | 查看排单总表 |
| Card 2 | 更新交期 | 查看库存详情 |
| Card 3 | 查看大盘 | — |

## 评审结论

三路评审的综合意见是：设计方案核心方向正确，但需要根据技术约束和业务需求进行务实调整。修订后的方案可进入 Phase 1+2 实施阶段。
