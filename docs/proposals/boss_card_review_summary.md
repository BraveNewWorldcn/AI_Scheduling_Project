## P0 致命问题（必须解决才能上线）

| # | 问题 | 来源 | 修订方案 |
|---|------|------|---------|
| 1 | **色盲用户无法区分红绿状态** — 10% 男性高管受影响 | UI 设计师 | 每种状态配非颜色指示器：正常="✓ 正常"、关注="⚠ 关注"、告警="● 告警" |
| 2 | **"今日结论"被视觉消灭** — 1行 vs 决策清单4行，权重倒挂 | UI 设计师 | 结论区加浅灰底背景块，让它从视觉上成为"摘要卡片" |
| 3 | **数据源严重不足** — 目标值、责任人、合同金额全部不存在 | 技术 | 分两期：MVP 用环境变量+角色标签，二期建数据表 |
| 4 | **决策条目无上限** — 极端日 6 条异常卡片崩溃 | UI 设计师 | 硬截断为最多 3 条 + "查看全部" |
| 5 | **缺趋势预警** — 连续绿色但 Lead Time 暗涨，老板不知 | 产品经理 | 结论句加趋势："较上周 Lead Time +4 天"；再加"防御性不安"规则 |

## 修订后实施方案

### Phase 1 MVP（零数据依赖，约 40 行改动）

改动 `_build_boss_card` 函数：

1. **三格仪表盘**：交付率（含目标90%）+ 库存健康度（含目标80%）+ 需关注项数
2. **颜色双通道**：`<text_tag color='green'>正常</text_tag>` 等，color + text 同时编码
3. **今日结论**：浅灰底背景块包裹 + 文字趋势（如"较上周 +2 天"）
4. **"需关注"（非"需决策"）**：最多 3 条，每条含角色标签如"[采购]"、"[交付]"
5. **按钮**：静态 2 个（查看详情 + 查看交付明细）
6. **Header 颜色**：正常时蓝色，异常时才黄色/红色
7. **灰度信息行**：`note` 内显示"今日共 X 项异常，Y 项需关注，Z 项执行层闭环中"
8. **排单员卡片微调**：审计和缺料拆为两段

### Phase 1 不实现
- ❌ 合同金额筛选
- ❌ 具体人名映射（显示角色标签即可）
- ❌ 动态按钮

## 设计规范补丁

### 色盲友好编码
```
绿色卡片 → "✓ 正常" + 绿色 text_tag
黄色卡片 → "⚠ 关注" + 橙色 text_tag
红色卡片 → "● 告警" + 红色 text_tag
```

### 条目截断规则
```
"需关注"最多 3 条
超过 3 条 → 第 4 行 "[查看全部 N 项异常]"
```

### 防御性不安规则
```
连续 7 天绿色 + Lead Time 上升 → 强制升级黄色
连续 14 天绿色 → 强制升级黄色（"持续性沉默检查"）
```
