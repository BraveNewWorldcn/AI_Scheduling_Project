# 老板卡片（Card 3）重设计方案 v3

> 问题：当前卡片信息过载、制造焦虑、缺乏目标对比、缺少行动指引
> 目标：3秒看清全局 → 知道要不要介入 → 一键行动
> 制约：飞书卡片不支持图表（折线图/柱状图不可用），所有内容限于飞书原生组件

---

## 一、核心原则

### 1.1 3秒法则
老板看一眼卡片就知道：**今天有没有问题，有问题谁负责，没问题就划走**。

### 1.2 不制造焦虑规则
- 每条异常信息必须附带**行动建议**（谁在处理/截止时间）
- 不堆砌数字制造恐慌感（"306个物料断供"不出现，只出现"影响X个项目"）
- 颜色传递严重度，但文字传达"这事有人在管"

### 1.3 分层推送
| 层级 | 看什么 | 谁看 |
|------|--------|------|
| 指标层 | 交付率/健康度/需关注项 | 老板（3秒） |
| 结论层 | 1句话："今天交付缺口6%，3项需要关注" | 老板（10秒） |
| 行动层 | 需老板决策的具体事项 | 老板（决定介入） |
| 明细层 | 缺货详表、延迟订单列表 | 采购/交付负责人 |

```

│  ┌──────────┬──────────┬──────────┐          │

│  │  84%      │  72%      │   3项     │          │
│  │  目标 90% │  目标 80% │  较昨日-1  │          │     带目标对比+环比

│                                               │
```

## 三、指标设计

### 3.1 老板卡片只保留 3 个指标（从原来的 4+ 改为 3）

| # | 指标 | 为什么保留 | 目标值来源 | 异常阈值 |
|---|------|-----------|-----------|---------|
| 1 | 交付率 | CEO最关心的KPI | 公司年度目标 | < 90% 黄色, < 80% 红色 |
| 2 | 库存健康度 | 资金占用效率 | SKU标准表的安全库存 | < 80% 黄色, < 60% 红色 |
| 3 | 需关注风险项 | 需要老板过问的异常数 | — | ≥ 3 黄色, ≥ 5 红色 |

### 3.2 去掉的指标及原因

| 去掉的指标 | 原因 | 该谁看 |
|-----------|------|--------|
| Lead Time（18天） | 过程指标，老板只关心结果 | 运营经理 |
| 产能池饥饿度 | 太细，老板不需要 | 排产主管 |
| 延迟订单计数 | 合并到"需关注风险项" | — |

## 四、颜色语义

| 状态 | 头部颜色 | 触发条件 |
|------|---------|---------|
| 正常 | green | 交付率 ≥ 90% 且 需关注 ≤ 2 |
| 关注 | yellow | 80% ≤ 交付率 < 90%，或 3 ≤ 需关注 ≤ 5 |
| 告警 | red | 交付率 < 80%，或 需关注 > 5，或有 P0 项目受阻 |

---

## 五、"需老板决策"筛选规则

### 5.1 入选条件（满足任一即入选）

| 条件 | 示例 |
|------|------|
| 影响金额 > 100 万的合同受阻 | "某客户·XX合同 标的230万，缺货延迟" |
| 需要跨部门协调资源 | "采购总监需与供应商确认替代方案" |
| 客户已催单或存在违约风险 | "XX项目交付延迟5天，客户已书面催单" |

### 5.2 排除条件（即使异常也不进老板卡片）

| 条件 | 原因 | 给谁 |
|------|------|------|
| 执行层可自行解决的缺货 | 老板不需要知道每一个SKU | 采购负责人 |
| 单日波动（昨日+5今日-3之类） | 正常波动 | 运营看板 |
| 备料冗余导致的"账面上断供" | 不阻塞实际排产的料 | 不需要通知任何人 |

## 六、附带微调：排单员卡片审计+缺料分段

当前一行写法：
```
审计通过 抽查5/61 4/4规则无异常 | 紧缺物料：用户信息传输装置
```

改为两段：
```
<审计通过> 抽查5/61 4/4规则无异常

紧缺物料：用户信息传输装置（缺34个）
影响项目：XX高校智慧教室
```

## 七、技术可行性

| 设计元素 | 可行性 | 实现方式 |
|---------|:---:|------|
| 三格仪表盘（含目标对比行） | ✅ | `column_set` flex_mode:trisect |
| 颜色动态 header | ✅ | `template: "green"/"yellow"/"red"` 变量 |
| text_tag 标签 | ✅ | `<text_tag color='green'>今日结论</text_tag>` |
| 需关注风险项动态填充 | ✅ | Python 条件判断 + 字符串拼接 |
| 折线图/柱状图/趋势图 | ❌ | 飞书卡片不支持，改用文字环比 |
| 操作按钮 | ✅ | `action` + `button`，最多 3 个 |

---

## 八、Non-goals（明确不做）

- ❌ 不在飞书卡片内嵌入图表（报表/历史趋势线）
- ❌ 不给老板看完整缺货清单（那是给采购的）
- ❌ 不展示执行层的过程指标（Lead Time / 产能池）
- ❌ 不展示所有物料的具体SKU编号（仅列出受阻项目名）
