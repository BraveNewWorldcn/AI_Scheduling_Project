## 三、数据同步机制

### 3.1 触发方式

独立的同步操作（与排单分开）。在**独立的财务核算界面**中提供「同步对账数据」按钮，点击触发。

### 3.2 同步模式

**Upsert 模式**：已存在的合同/明细行更新，不存在的则新增，销售订单中不存在的在对账表中保留不动。

### 3.3 对账总表同步

```
销售订单主表 ──→ 财务对账总表
同步字段：合同编号、下单日期、客户名称、项目名称、商务、代理商
```

- 「项目类型」「备注」「AI项目金额」「人工核对金额」「AI费用检查」不同步，保留原有值

### 3.4 对账明细表同步

```
销售订单明细表 ──→ 财务对账明细表
同步字段：合同编号、产品名称、规格、合同数量

销售订单主表   ──→ 财务对账明细表
同步字段：项目名称（按合同编号关联）

产品计费规则主表 ──→ 财务对账明细表
同步字段：Spec_ID（产品名称=产品名称 且 规格=规格型号，同时匹配别名；匹配不到留空）
```

- 「合同类型」：从对账总表「项目类型」同步（按合同编号关联）
- 「是否计入包干」「包干合同单采数量」「单采价格」「小计」：不同步，由核算流程填写

## 四、核算流程

### 4.1 触发方式

财务核算界面「财务核算」按钮，点击触发完整核算流程。

### 4.2 前置检查

对每个合同，检查总表的「人工核对金额」是否已填写。**若已填写，锁定该合同**，跳过该合同的所有核算和回写（总表行 + 对应明细表行均不修改）。

### 4.3 包干项目完整性检查

对总表「项目类型」= 包干的合同：

1. 检查明细表中是否包含产品「消防远程控制服务费」和「消防远程控制包干费」
2. 若缺少，**自动补行**：
   - 产品名称 = "消防远程控制服务费"，规格 = "定制"，合同数量 = 1
   - 产品名称 = "消防远程控制包干费"，规格 = "定制"，合同数量 = 1
3. 检查明细表中 Spec_ID = SPEC-RB800-KZP 且产品名称包含「主键盘」的合同数量合计，若 > **阈值（页面输入框，默认 3）**：
   - 新增一行：产品名称 = "消防远程控制设备费"，规格 = "定制"，合同数量 = 合计 - 阈值
   - 在「AI费用检查」中标注「AI巡查增加设备费用」
4. 全部检查完成后，回写总表「AI费用检查」字段：全部正常写「正常」，有异常写异常描述（含上述设备费标注）

### 4.4 核算步骤（按合同逐条处理）

#### 4.4.1 包干项目

对明细表每一行，根据 Spec_ID 匹配计费规则主表：

- **单采设备**（计费方式 = 单采 且 包干阈值 = 0）：
  - 是否计入包干 = 否
  - 单采价格 = 计费规则「单采单价」
  - 小计 = 合同数量 × 单采价格

- **包干产品**（计费方式 ≠ 单采 且 包干阈值 ≠ 0）：
  - 是否计入包干 = 是
  - 合同数量 ≤ 包干阈值（阈值内）：
    - 单采价格 = 0
    - 包干合同单采数量 = 0
    - 小计 = 0
  - 合同数量 > 包干阈值（阈值外）：
    - 包干合同单采数量 = 合同数量 - 包干阈值
    - 单采价格 = 计费规则「单采单价」
    - 小计 = 包干合同单采数量 × 单采价格

#### 4.4.2 单采项目

对明细表每一行：

- 是否计入包干 = 否
- 包干合同单采数量 = 合同数量
- 单采价格 = 计费规则「单采单价」
- 小计 = 合同数量 × 单采价格

### 4.5 汇总回写

- 明细表按合同编号汇总「小计」 → 填写总表对应行的「AI项目金额」
- 锁定的合同（人工核对金额已填写）跳过不回写

## 五、界面设计

### 5.1 财务核算界面

**独立页面**（与现有排单管理页面分开），路径：`/finance`

界面元素：
- **阈值输入框**：RB800-KZP 设备费阈值，默认值 3，核算前可手动修改
- **「同步对账数据」按钮**：触发 `/finance/sync`
- **「财务核算」按钮**：触发 `/finance/calculate`
- **执行状态/结果展示区域**：显示同步和核算的执行结果

## 六、接口设计

| 端点 | 方法 | 请求参数 | 说明 |
|------|------|------|------|
| `/finance/sync` | POST | — | 同步对账总表及明细表数据 |
| `/finance/calculate` | POST | `threshold: int = 3` | 执行完整财务核算流程（阈值从页面传入） |

| 路径 | 说明 |
|------|------|
| `/` | 现有排单管理页面（不变） |

## 七、约束与规则汇总

| # | 规则 |
|---|------|
| 1 | 产品计费规则主表禁止 AI 改写，仅人工维护 |
| 2 | 同步操作和核算操作独立，各自触发 |
| 3 | 人工核对金额已填写的合同，再次核算时完全锁定 |
| 4 | Spec_ID 匹配不到则留空，不报错 |
| 5 | 包干项目缺少消防远程控制产品时自动补行 |
| 6 | 阶梯单价和特殊说明暂不参与核算逻辑 |
| 7 | 别名字段参与产品匹配（模糊匹配，支持包含关系） |
