# AI排单系统

这是一个基于FastAPI的AI排单系统，每天北京时间早上10点自动从飞书文档读取数据，进行智能排单计算。

## 功能特性

- 🕙 **自动调度**: 每天北京时间10:00自动执行排单
- 🔒 **人工锁单保护**: 已人工确认的订单不被重新排单，但仍占用库存
- 📊 **智能库存计算**: 考虑已锁单库存占用情况
- 📈 **AI排单算法**: 根据产品类型、库存状态计算发货周期
- 📋 **飞书集成**: 自动读取和写入飞书多维表格

## 核心业务逻辑

### 排单规则
1. **优先级处理**: 紧急订单、换货、补发订单优先处理（2天发货）
2. **项目类型区分**:
   - 远程控制项目: 根据库存状态和产品特性计算周期
   - 常规项目: 根据外采/自研属性计算周期
3. **库存检查**: 计算缺口数量，确定发货时间

### 人工确认机制
- 已确认订单（"是否人工确认"="是"）不会被AI重新排单
- 但这些订单仍占用库存，影响其他订单的排单计算
- 确认订单保留原有排单结果

## 安装和运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
创建 `.env` 文件或设置环境变量：
```bash
# 飞书配置
FEISHU_APP_ID=your_app_id
FEISHU_APP_SECRET=your_app_secret
BITABLE_APP_TOKEN=your_bitable_token

# 表格ID配置
TABLE_ID_ITEMS=tblJn5iP6imjzE8h    # 销售订单明细表
TABLE_ID_SKU=tblVAGWeGHvmbFgJ      # SKU标准表
TABLE_ID_INV=tblFZNdEwW50izjh      # 库存快照表
TABLE_ID_SUMMARY=tblgMzZPyBBU5GLX  # 合同缺货总览表
TABLE_ID_DETAIL=tbl09Z6C7wCGh3mW   # AI排单总表
```

### 3. 运行服务
```bash
python scheduler_api.py
```

服务将在 http://localhost:8000 启动

## API接口

### POST /schedule
手动触发排单计算
```bash
curl -X POST http://localhost:8000/schedule
```

### POST /webhook/feishu
飞书Webhook接口（用于数据更新通知）

## 数据流程

1. **数据读取**: 从飞书多维表格读取订单、SKU、库存数据
2. **缓存管理**: 本地缓存数据，避免频繁API调用
3. **排单计算**:
   - 检查人工确认订单，跳过重算但保留库存占用
   - 计算每个SKU的可用库存（扣除已锁单占用）
   - 根据业务规则计算发货周期
   - 生成排单建议
4. **结果写入**: 将排单结果写回飞书表格

## 缓存机制

- **数据缓存**: 本地pickle文件缓存飞书数据
- **时间控制**: 每天10点后只刷新一次数据
- **锁单保护**: CSV文件保存历史排单结果

## 日志输出

系统会输出详细的执行日志，包括：
- 数据加载状态
- 排单计算过程
- 库存占用情况
- 写入结果状态

## 注意事项

1. 确保飞书应用有足够的数据表访问权限
2. 定期检查缓存文件是否正常
3. 监控系统日志，及时处理异常情况
4. 备份重要的排单结果数据
